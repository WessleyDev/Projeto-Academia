
# Projeto Academia

Projeto fictício de uma academia, desenvolvido como parte dos meus estudos em Front-end.

## Sobre o projeto

O projeto consiste em uma interface de login e cadastro para uma academia fictícia, com uma proposta visual moderna e intuitiva.

A interface contará com adaptação para dispositivos móveis, proporcionando uma melhor experiência em diferentes tamanhos de tela.

## Tecnologias utilizadas

- HTML5
- CSS3

## Funcionalidades

- Tela de login.
- Tela de cadastro.
- Navegação entre as telas.
- Layout responsivo para desktop e dispositivos móveis.

## Objetivo

Praticar meus conhecimentos em HTML e CSS, trabalhando com estruturação de páginas, estilização, posicionamento de elementos e responsividade.
